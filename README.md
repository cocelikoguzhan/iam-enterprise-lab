# Enterprise IAM Lab

A hands-on Identity and Access Management portfolio project built with
Microsoft Entra ID, Microsoft 365, PowerShell, and Microsoft Graph.

## Project Goal

The goal of this lab is to simulate the identity infrastructure of a fictional
company and implement real-world IAM scenarios while studying for the
Microsoft SC-300: Identity and Access Administrator certification.

## Environment

- Microsoft Entra ID
- Microsoft Entra ID P2
- Microsoft 365 E5
- Azure
- PowerShell
- Microsoft Graph

## Lab Areas

- User and group lifecycle management
- Administrative roles and RBAC
- Multi-Factor Authentication
- Conditional Access
- Privileged Identity Management
- Identity Protection
- Access Reviews
- Enterprise Applications
- App Registrations
- Microsoft Graph automation
- PowerShell automation
- Hybrid Identity
