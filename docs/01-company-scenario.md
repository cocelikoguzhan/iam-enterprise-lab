# Company Scenario

## Company Overview

This lab simulates the identity and access management environment of a fictional company.

Company name: CLK Group

CLK Group is a growing technology and services company with multiple departments and cloud-based business operations.

## Departments

- IT
- Human Resources
- Finance
- Sales
- Management

## IAM Goals

The company needs a secure and manageable identity environment using Microsoft Entra ID and Microsoft 365.

Key goals include:

- Centralized identity management
- Role-based access control
- Multi-Factor Authentication
- Conditional Access
- Privileged Identity Management
- Identity Protection
- Access Reviews
- Secure application access
- Automated user and group management

## Current Lab Environment

- Microsoft Entra ID
- Microsoft Entra ID P2
- Microsoft 365 E5
- Azure
- PowerShell
- Microsoft Graph
